
# Greek & Energy Bot — Telegram

Бот на Python для двух задач:
- учёт энергетиков: бренд, объём, введённое пользователем количество кофеина;
- изучение современного греческого с нуля, с учебными метками CEFR A1–C2.

## Что работает в этой версии

- `/start`, `/menu`, `/help`, `/lesson`, `/energy`, `/stats`;
- меню-кнопки Telegram;
- учебные карточки и мини-тесты;
- SQLite-база пользователей, напитков, результатов и пройденных уроков;
- дневная и месячная статистика объёма и кофеина;
- базовые материалы от A1 до C2.

**Честно о полноте курса:** это работающий MVP с несколькими демонстрационными уроками, а не полный учебник на шесть уровней и не официальный CEFR-экзамен. Уровень нельзя достоверно присвоить по одному тесту с вариантами ответа. В следующих версиях следует добавить полноценные модули, аудирование, произношение, письменные задания, интервальное повторение и экзаменационные тренировочные тесты.

## Запуск на компьютере

Требуется Python 3.11 или новее.

1. Создайте бота у `@BotFather` в Telegram через `/newbot`.
2. Скопируйте токен. Никому его не отправляйте.
3. Установите Python.
4. В папке проекта создайте `.env` на основе `.env.example` и вставьте токен.
5. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python bot.py
   ```

   В Windows активация виртуального окружения: `.venv\Scripts\activate`.

6. Откройте своего бота в Telegram и отправьте `/start`.

## Запуск только с iPhone через облачную IDE

Самый простой сценарий — Replit в Safari. Названия кнопок могут меняться.

1. Создайте репозиторий GitHub или загрузите файлы проекта в Replit.
2. Откройте Replit в Safari и создайте Python-проект.
3. Добавьте файлы `bot.py` и `requirements.txt` (и остальные файлы при необходимости).
4. В разделе Secrets / Environment Variables добавьте секрет `BOT_TOKEN` со значением токена от BotFather. Не вставляйте токен в код или публичный репозиторий.
5. В Shell / Console выполните `pip install -r requirements.txt`.
6. Запустите `python bot.py`.
7. Откройте бота в Telegram и отправьте `/start`.

Важно: бесплатные облачные среды могут останавливать процессы или ограничивать постоянную работу. Для круглосуточного бота нужен постоянно работающий worker/сервер. Выбирайте хостинг, который поддерживает длительно работающий Python-процесс; веб-сайт не нужен, так как бот использует Telegram long polling.

## Запись энергетика

Нажмите «Записать энергетик» и отправьте:

`Monster, 500, 160`

Поля: бренд, объём в миллилитрах, кофеин в миллиграммах. Проверяйте кофеин на этикетке: он зависит от страны, рецептуры и размера банки. Если количество неизвестно, можно ввести `0`, но это не означает, что кофеина нет.

## Данные и приватность

Бот хранит Telegram user ID, имя профиля, записи напитков и результаты уроков в `bot.db`. Не публикуйте эту базу. При размещении у хостинг-провайдера проверьте его условия хранения данных и сделайте резервное копирование.

## Важное о кофеине

Бот только записывает введённые значения и не рассчитывает индивидуальную безопасную дозу. Для здоровых взрослых часто приводят ориентир до 400 мг кофеина в сутки, но это не универсальная цель и не гарантия безопасности; чувствительность, беременность, возраст, лекарства и заболевания меняют рекомендации. Не используйте бот как медицинский совет. Лучше не настраивать геймификацию так, чтобы она поощряла пить больше энергетиков.

## Структура проекта

- `bot.py` — Telegram-логика, уроки, тесты и статистика;
- `requirements.txt` — Python-зависимости;
- `.env.example` — шаблон настроек;
- `.gitignore` — защита секретов и базы данных от случайного коммита.
